## Networking & Wi-Fi

### Wi-Fi Standards (802.11)

* **802.11n (Wi-Fi 4)** → 2.4 GHz & 5 GHz
* **802.11ac (Wi-Fi 5)** → 5 GHz only, higher speeds
* **802.11ax (Wi-Fi 6 / 6E)** → 2.4, 5, 6 GHz, better performance in crowded networks
* **802.11be (Wi-Fi 7)** → emerging, very high speeds

### Key Concepts

* **Latency** → delay (ms)
* **Throughput** → actual data transfer rate (Mbps/Gbps)

### TCP vs UDP

* **TCP** → reliable, connection-based, slower
* **UDP** → faster, no guarantee, used in streaming

---

## Security Concepts

### Wi-Fi Security

* **WEP** → insecure (deprecated)
* **WPA2** → AES encryption (strong)
* **WPA3** → strongest, uses SAE authentication

### Attacks

* **MITM (Man-in-the-Middle)** → attacker intercepts communication
* **Snooping** → passive listening
* **Wiretapping** → intercepting data transmission

### Prevention

* Use HTTPS (SSL/TLS)
* Use VPNs
* Avoid public Wi-Fi
* Validate certificates

---

## Storage & Redundancy

### RAID

* **RAID 0** → performance, no redundancy
* **RAID 1** → mirroring (redundancy)
* **RAID 5** → balanced (parity)
* **RAID 10** → performance + redundancy

### Storage Types

* **DAS** → direct, single device, faster
* **NAS** → network-based, shared, slightly slower

### Concepts

* **Redundancy** → extra components for backup
* **Fault Tolerance** → system continues without interruption

## APIs & Web Concepts

### API Basics

* API = communication between systems

### REST API Methods

* **GET** → retrieve data
* **POST** → create data
* **PUT** → update data
* **DELETE** → remove data

### Data Formats

* **JSON** → most common, lightweight
* **XML** → older, structured

---

## Databases

### SQL Commands

**DML (Data Manipulation Language)**

* SELECT
* INSERT
* UPDATE
* DELETE

**DDL (Data Definition Language)**

* CREATE
* ALTER
* DROP

### Database Types

* **Relational (SQL)** → structured, tables, ACID compliance
* **Non-relational (NoSQL)** → flexible, scalable, unstructured data

---

## Programming Concepts

### Compiled vs Interpreted

* **Compiled** → converted to machine code before execution (C, C++, Go)
* **Interpreted** → executed line-by-line (Python, JavaScript)

### Scripts vs Programs

* **Programs** → compiled, complex, standalone
* **Scripts** → interpreted, automation-focused

## Troubleshooting (CompTIA Method)

1. Identify the problem
2. Establish a theory
3. Test the theory
4. Plan and implement solution
5. Verify full functionality
6. Document findings

---

## Practice Test Insights

* Questions are more scenario-based than expected
* Small wording differences can change the answer
* Requires understanding, not memorization
* Eliminating wrong answers is a key strategy

---

## Key Takeaways

* Practice exams reveal real weaknesses
* Deep understanding > surface-level knowledge
* Rewriting notes improves retention
* Consistency and repetition are critical before the exam
