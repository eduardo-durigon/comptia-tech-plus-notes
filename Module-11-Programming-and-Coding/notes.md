## 2️⃣ Key Concepts Learned  

### 💻 What Is Coding  

Coding is the process of **writing instructions that computers can understand and execute**.

- Computers understand **binary (1s and 0s)**  
- Programming languages translate human logic into machine instructions  
- Used to build software, websites, and systems  

---

### 🧠 Syntax vs Semantics  

- **Syntax** → rules and structure of a programming language  
- **Semantics** → meaning of the code  

✔ Correct syntax + correct meaning = working program  
❌ Correct syntax + wrong meaning = incorrect results  

---

### 🧩 Programming Languages  

Different languages follow different rules but achieve similar results.

- Example:
  - Python → `print("Hello World")`  
  - JavaScript → `console.log("Hello World")`  

---

### ⚙️ Types of Programming Languages  

#### 🏗️ Compiled Languages  
- Code is converted into machine language before execution  
- Faster performance  
- Example: C, C++, Java  

#### 🔄 Interpreted Languages  
- Code is executed line by line  
- More flexible and portable  
- Example: Python, JavaScript  

---

### 🔁 Compiling vs Interpreting  

- **Compiler** → converts entire program into machine code  
- **Interpreter** → runs code step-by-step  

---

### 🧾 Markup Languages  

- Example: HTML, XML  
- Not programming languages  
- Used to structure and display content  

---

### 🧠 Assembly Language  

- Low-level programming language  
- Very close to hardware  
- Fast but difficult to write and maintain  

---

### 📊 Variables  

Variables are **containers used to store data**.

- Store values that can change  
- Must have a name (identifier)  
- Example:
  - `x = 10`  

---

### 🔢 Data Types  

Define what type of data is stored:

- **Integer** → whole numbers  
- **Float** → decimal numbers  
- **Boolean** → true/false  
- **String** → text  
- **Character** → single symbol  
- **Array/List** → collection of values  

✔ Using correct data types prevents errors and improves performance  

---

### 🔒 Constants  

- Similar to variables  
- Value **does not change**  
- Example: π (pi)  

---

### 🔤 Characters & Strings  

- Characters = single symbol  
- Strings = sequence of characters  
- Use quotes `" "` or `' '`  
- Escape characters allow special formatting  

---

### 🔗 Arrays & Vectors  

- Store multiple values  
- Access using index  
- Example: `[1, 2, 3]`  

- **Vectors** can change size dynamically  

---

### 🔍 Boolean Logic  

- Based on **true/false values**  

Operators:
- AND → both must be true  
- OR → one must be true  
- NOT → reverses value  

Used in decision-making  

---

### 🔁 Control Flow  

Programs follow a flow:

#### 1️⃣ Sequential  
- Runs step-by-step  

#### 2️⃣ Conditional  
- Uses decisions (if/else)  

#### 3️⃣ Loops  
- Repeats code  
- Examples:
  - `for` loop  
  - `while` loop  

#### 4️⃣ Functions  
- Reusable blocks of code  
- Improve organization and efficiency  

---

### 🧠 Functions  

- Perform a specific task  
- Can take inputs and return outputs  
- Help avoid repetition (DRY principle)  

---

### 🧱 Object-Oriented Programming (OOP)  

Programming based on real-world objects.

- **Class** → blueprint  
- **Object** → instance of a class  
- **Properties** → attributes  
- **Methods** → actions  

✔ Helps organize and structure complex programs  

---

### 🗺️ Planning Code  

Planning is essential before writing code.

#### Steps:
1. Define goals  
2. Break into tasks  
3. Create timeline  

---

### 📊 Flowcharts  

Visual representation of program logic:

- Oval → start/end  
- Rectangle → process  
- Diamond → decision  
- Parallelogram → input/output  

---

### ✍️ Pseudocode  

- Writing logic in plain language  
- Not actual code  
- Helps plan before coding  

---

### 🔄 Algorithms  

- Step-by-step solution to a problem  

Includes:
- Sequence  
- Decisions  
- Loops  

---

### 🧾 Comments  

- Notes inside code  
- Not executed by computer  
- Help explain logic  

Examples:
- Python → `# comment`  
- Java → `// comment`  

---

### 🌐 Query Languages  

- Used to interact with databases  
- Example: SQL  

- A **query** is a question asked to a database:
  1. Input query  
  2. Search data  
  3. Retrieve results  
  4. Display output  

---

### 🐞 Debugging & Troubleshooting  

- Process of finding and fixing errors (bugs)  

Techniques:
- Testing small parts  
- Checking logs  
- Reproducing issues  

---

### 💼 Careers in Coding  

- **Web Developer** (Frontend & Backend)  
- **Cloud Architect**  
- **Machine Learning Engineer**  
- **Game Developer**  

---

## 3️⃣ Key Takeaways  

- Coding is how humans communicate with computers  
- Syntax and logic must both be correct  
- Variables and data types are fundamental building blocks  
- Planning (flowcharts & pseudocode) improves code quality  
- Different languages serve different purposes  
- Debugging is a key skill in development  
- OOP helps structure complex systems
