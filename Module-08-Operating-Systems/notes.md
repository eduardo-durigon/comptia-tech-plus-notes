## Module 8: Operating Systems  

### 🖥️ What Is an Operating System  

An operating system is software that:
- Manages hardware and software resources  
- Provides a platform for applications  
- Allows users to interact with the computer  

Core responsibilities:
- Device management  
- Process management  
- File system organization  
- Security and permissions  
- User interface (CLI or GUI)  

---

### ⚙️ Types of Operating Systems  

**Proprietary OS**
- Designed for specific use cases  
- Not publicly available  

**Open Source OS**
- Source code is available  
- Example: Linux  

**Commercial OS**
- Requires a license  
- Examples: Windows, macOS  

---

### 💻 Popular Operating Systems  

**Windows**
- Widely used  
- Supports most hardware  
- Regular updates (Windows 7 → 10 → 11)  

**macOS**
- Designed by Apple  
- Based on UNIX  
- Strong integration with Apple hardware  

**Linux**
- Open source  
- Highly customizable  
- Common in servers and cybersecurity  

**Chrome OS**
- Cloud-based  
- Fast and lightweight  
- Relies heavily on internet access  

---

### 🖱️ CLI vs GUI  

**CLI (Command Line Interface)**
- Text-based  
- Faster and uses fewer resources  
- Powerful for scripting and remote management  

**GUI (Graphical User Interface)**
- Visual and user-friendly  
- Uses mouse/touch interactions  

---

### 🔌 Drivers and Devices  

Drivers allow the OS to communicate with hardware.

Key points:
- Plug and Play devices install automatically  
- Device Manager helps identify issues  
- Symbols (⚠️ ❌ ⬇️) indicate driver problems  
- Drivers can be updated, disabled, or reinstalled  

---

### 📊 Task Management & Processes  

A **process** is a running program.

Task Manager allows you to:
- View CPU, memory, disk, and network usage  
- End tasks  
- Manage startup applications  
- Monitor system performance  

Too many processes can slow down a system.

---

### ⚙️ System Services  

Services run in the background without user interaction.

Examples:
- DHCP  
- DNS  
- TCP/IP  

You can:
- Start / stop services  
- Configure them  
- Monitor performance  

---

### 🗂️ File Systems & Storage  

A file system organizes data on storage devices.

**Examples:**
- NTFS (Windows)  
- APFS (Apple)  
- FAT32 / exFAT  

Key concepts:
- Root directory (C:\)  
- Paths (folder structure)  
- Metadata (file properties)  

---

### 📁 File Management  

Each file has:
- A **name**
- A **path**

Important actions:
- Create, copy, move, rename, delete files  
- Organize using folders  
- Use File Explorer (Windows) or Finder (macOS)  

---

### 🧾 File Types & Extensions  

File extensions determine how files are opened.

Examples:
- `.docx`, `.pdf`, `.mp3`, `.exe`, `.app`, `.elf`  

Default programs can be changed manually.

---

### 🫥 Hidden Files  

- Not visible by default  
- Can be enabled in system settings  
- Often used for system configurations  

---

### 🧠 Data Backup  

Backups protect against data loss.

**What to back up:**
- Personal files  
- Important system configurations  

---

### 💾 Types of Backups  

**Full Backup**
- Copies everything  

**Incremental Backup**
- Copies only changes since last backup  

---

### 💿 Backup Methods  

**Local Backup**
- External drives, USB, SD cards  

**Cloud Backup**
- Google Drive, OneDrive, iCloud  

**Business Backup Services**
- Carbonite  
- Backblaze  

---

### 🧪 Backup Best Practices  

- Automate backups  
- Use multiple backup locations  
- Test backups regularly  
- Ensure backups are complete  

---

### 🔁 Data Recovery  

- Recycle Bin / Trash allows recovery  
- Permanent deletion removes files completely  
- System restore points allow rollback  

---

### 🧱 Disk Management & Maintenance  

**Partitioning**
- Divides a drive into sections  

**Formatting**
- Prepares a drive with a file system  

**Fragmentation**
- Files split across disk → slower performance  

**Defragmentation**
- Reorganizes files → improves performance  

---

### 🔐 File System Features  

- **Compression:** reduces file size  
- **Encryption:** protects data  
- **Permissions (ACL):** controls access  
- **Journaling:** helps recover from crashes  

---

## 3️⃣ Key Takeaways  

- Operating systems manage hardware, software, and user interaction.  
- File systems organize and control how data is stored and accessed.  
- Task Manager and system tools are essential for troubleshooting.  
- Backups are critical and should always be tested.  
- Understanding file structures and permissions improves security and efficiency.
