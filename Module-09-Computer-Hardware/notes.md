# Module 9: Hardware

## 🧠 What Is Hardware

Hardware refers to the **physical components of a computer system** that work together to process data and run software.

Examples include:
- CPU
- Motherboard
- RAM
- Storage devices
- Peripherals (keyboard, mouse, monitor)

---

## 🧩 Motherboards

The motherboard connects all components together.

### Types:

**Proprietary**
- Designed for specific systems (e.g., Dell, HP)
- Only fits certain cases

**Standardized (ATX)**
- Industry standard size and layout
- Compatible with many cases and components
- Example: ATX (12 x 9 inches)

### Key Points:
- Contains sockets for CPU and RAM
- Includes expansion slots (PCIe)
- Uses a 24-pin power connector

---

## ⚙️ CPU (Central Processing Unit)

The CPU is the **brain of the computer**.

### Key Concepts:
- Executes instructions from programs
- Processes billions of operations per second
- Speed measured in **GHz (gigahertz)**

### Features:
- Cores (4, 8, 16+)
- Hyper-threading / Multi-threading
- Cache memory (small, fast memory inside CPU)

### Manufacturers:
- Intel
- AMD
- Apple (M-series chips)

---

## 🌡️ CPU Cooling

CPUs generate heat and require cooling:

- Heat sinks
- Fans
- Thermal paste
- Active vs passive cooling

---

## 💾 Memory (RAM)

RAM is **temporary (volatile) memory** used while programs are running.

### Key Points:
- Stores instructions and data for active tasks
- Faster than storage drives
- Data is lost when power is off

### Types:
- RAM → volatile, fast  
- ROM → non-volatile, permanent

### Features:
- DIMM (Dual Inline Memory Module)
- DDR (DDR2, DDR3, DDR4, DDR5)
- Typical sizes: 4GB – 32GB+

---

## 🧠 Storage Devices

### HDD (Hard Disk Drive)
- Magnetic storage
- Moving parts
- Slower but cheaper

### SSD (Solid State Drive)
- Flash memory
- No moving parts
- Faster and more reliable

### M.2 & NVMe
- Faster connection than SATA
- Uses PCIe interface
- High-speed data transfer

---

## 🔌 Storage Interfaces

- SATA → standard connection for drives
- PCIe → faster interface (used for SSDs, GPUs)

---

## 💿 Optical Drives

- CD-ROM (~700MB)
- DVD (~4.7GB)
- Blu-ray (~25GB)

Uses lasers to read/write data.

---

## 🔗 Expansion Slots & Buses

- PCIe slots (x1, x4, x8, x16)

Used for:
- GPUs
- Network cards
- Expansion cards

Buses allow communication between components.

---

## 🎮 Graphics (GPU)

### Types:

**Integrated graphics**
- Built into CPU
- Uses system memory

**Dedicated GPU**
- Separate hardware
- High performance (gaming, AI, video editing)

### Features:
- VRAM (video memory)
- Multiple display outputs (HDMI, DisplayPort)
- Ray tracing (realistic lighting)

---

## 🖥️ Resolution & Frame Rate

- Resolution: number of pixels (e.g., 1920x1080, 4K)
- Frame rate: measured in FPS (30–120+)
- Higher values = better visual quality

---

## 🌐 Network Interface Card (NIC)

Allows connection to networks.

### Types:
- Wired (RJ-45 / Ethernet)
- Wireless (Wi-Fi)

### Speeds:
- 10 Mbps → early networks  
- 1 Gbps → common today  
- 10 Gbps → high-end systems  

---

## 🔌 Ports & Connections

### Common Ports:
- USB (Type A, Type C)
- HDMI / DisplayPort
- RJ-45 (Ethernet)
- Audio jacks (3.5mm)

---

## 🔊 Audio & Video Devices

- Speakers and headphones (stereo / surround sound)
- SPDIF for high-end audio
- Cameras and microphones for video calls
- Projectors for presentations

---

## 🖨️ Printers & Scanners

### Printer Types:

**Inkjet**
- Uses liquid ink
- Good for home use

**Laser**
- Uses toner powder
- Faster, used in business

### 3D Printers:
- Create objects using layers of material

---

## 📄 Scanning Technology

- OCR (Optical Character Recognition)
  - Converts scanned images into editable text

- ADF (Automatic Document Feeder)
  - Automatically feeds multiple pages into scanner

---

## 🔌 Plug and Play

- Devices are automatically detected
- OS installs drivers automatically
- Uses hardware ID to find correct drivers

---

## 🧾 Drivers

Drivers allow the OS to communicate with hardware.

### Key Points:
- Can be installed automatically or manually
- Must match system (32-bit / 64-bit)
- Can be updated via Windows or manufacturer

---

## 🔋 Uninterruptible Power Supply (UPS)

Provides backup power during outages.

### Features:
- Protects against power surges
- Keeps system running temporarily

Measured in:
- VA (volt-amperes)
- Runtime (minutes)

---

## 🗂️ Storage Networks

### SAN (Storage Area Network)
- High-speed network for storage
- Centralized data storage
- Used by businesses

### NAS (Network Attached Storage)
- Smaller version of SAN
- Connected to LAN
- Allows file sharing

### RAID
- Combines multiple drives
- Improves performance and redundancy

---

## ☁️ Cloud Storage

Stores data on remote servers.

### Benefits:
- Scalability
- Accessibility
- Backup and version control
- Collaboration

### Examples:
- Google Drive
- OneDrive
- iCloud
- Dropbox

### Drawbacks:
- Cost
- Internet dependency
- Environmental impact

---

## 🔢 Units of Speed & Data

### Speed:
- Hertz (Hz)
- MHz (million cycles/sec)
- GHz (billion cycles/sec)

### Data Transfer:
- bps
- Mbps
- Gbps
- Tbps

### Throughput:
- Amount of data moved per second

---

## 🔄 Serial vs Parallel Communication

### Serial:
- One bit at a time
- Used in USB and networks

### Parallel:
- Multiple bits at once
- Faster but more complex

---

## 3️⃣ Key Takeaways

- Hardware components work together to process and store data.
- CPUs, RAM, and storage directly impact performance.
- SSDs and NVMe are much faster than HDDs.
- GPUs are essential for graphics, gaming, and AI.
- Storage and networking systems (SAN, NAS, cloud) are widely used in real environments.
